# Neutral Color Balance Prompt

Use this prompt when editing an existing image to remove warm color casts.

---

## Full Prompt (for Image Editors: DALL-E, GPT-4o, Gemini, Midjourney, Firefly, etc.)

```
Edit the uploaded image to remove the yellow/orange warm tint and make the color balance clean and neutral.

Preserve:
- Original layout and composition
- Products, logos, labels
- Prices, addresses, all visible text
- Overall design structure

Apply:
- Neutral daylight-balanced white balance (5600K)
- Accurate product colors
- Clean whites (not cream/yellow)
- Deep neutral blacks (not brown)
- Natural contrast
- Crisp modern commercial lighting

Avoid:
- Yellow tint, orange cast, warm filter
- Sepia tone, amber lighting
- Golden-hour color grading
- Vintage look, old painting effect
- Oversaturated warm tones
- Brown overlay, muddy colors

Do not redesign. Do not change composition. Do not alter text/labels.
```

---

## Short Add-on Version (append to any prompt)

```
Color grading: neutral daylight-balanced white balance, accurate colors, clean whites, neutral blacks, no yellow tint, no sepia, no orange cast, no warm filter, no vintage grading, no golden-hour lighting.
```

## Specialized Variants

### For Product/Ad Images
```
Use neutral daylight-balanced lighting with accurate product colors. Avoid warm yellow tint, sepia, orange cast, vintage filter, golden-hour lighting, or overly saturated amber tones. Whites must appear clean white, not cream or yellow. Preserve all text, logos, prices, addresses exactly.
```

### For Food Images
```
The food should look appetizing while preserving accurate, neutral colors. Do not use golden food photography filters or warm amber lighting. Use neutral studio product lighting. Greens must stay green, whites clean white, meats natural color.
```

### For Cinematic/Fantasy (Neutral Look)
```
Cool-neutral studio lighting, modern digital art style, crisp clean rendering, balanced RGB colors, no warm overlay, no cinematic orange/teal grading. Pure whites, deep neutral blacks, natural skin tones.
```

### Color Temperature Explicit
```
Lighting at 5500K-5600K daylight balance, neutral white balance, accurate commercial product colors.
```
